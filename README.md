# potTreeToolkit
R package for processing pot data for phylogenetics

## Installation
```
pak::pkg_install("joelh251/potTreeToolkit")
```

## Documentation
This package collects a variety of functions into 4 R6 classes. 

These are:
- potDataProcessor
- treeProcessor
- optimalTraitsFinder
- supertreeUtils

You can learn how these work using the help utility in R. e.g.
```
?potDataProcessor
```

## Referencing
You may call `citation("potTreeToolkit")` in R to generate a citation key.
